# Pilot 安全与保留策略

状态：规范；适用于 Ticket 26、KB-SO-002/003，以及 KB-UX-007、
KB-FB-001/002 的隐私部分。ADR 0007 记录本决策。

## 内容准入

已审核来源在不可变定义和批准导出中保留 `content_admission`。
`material_class` 只能为 `public_material`、`team_shared_internal`、
`sanitized_bounded_internal_case`。必须声明 `audience=all_admitted_members`、
`sensitivity=restricted`、`sanitized=true`。公开材料使用公开访问；
内部材料使用受控访问；有界内部案例必须使用脱敏案例类别。声明不授予发布
权威，仍须负责的 Maintainer 核实、不同 Reviewer 批准、Candidate 检查、
验收及显式发布。

密钥、凭据、个人或客户数据、生产原始转储、未脱敏日志或截图、仅部分成员
获授权或混合敏感度材料、危险的未公开漏洞利用细节都不是可准入类别。
编辑和旧上传持久化前检查可识别的凭据及个人信息形状。模式不能证明所有敏感
事实均不存在，人工审核仍承担责任。旧上传不能发布。缺失准入声明代表未核实，
不能据此伪造批准或改写旧哈希。
上传、定位符和编辑检查共享同一份命名凭据规则，个人信息规则单独组合。
准入检查原始字符串及最多三轮百分号解码；仍需继续解码的输入在此有界
边界被拒绝，不推定为安全。

`sanitize_public_source_url` 准备不含凭据、不安全查询数据或片段的公开
HTTPS 定位符，并拒绝私网、本地地址及控制字符。编辑与解析器权威只接受
已规范化定位符；不安全输入被拒绝，而不是在哈希工件内部改写。
仅保留有界的 `version`、`v`、`revision`、`rev`、`page`、`lang` 查询选择器。
准备阶段移除其他参数、可识别凭据和私有地址值；权威校验拒绝未清洗输入。
原始或编码 URL 路径中的可识别私有材料直接拒绝，不能作为规范路径保留，
也不能静默改写成另一个来源。

## 私有记录

会话和反馈按所有者限制。其他成员及管理员得到与不存在私有记录相同的空结果
或不执行删除结果，没有管理员转录绕过。会话删除遵循 Ticket 20 写入隔离，
移除消息和私有执行头、事件。保留期间，撤回历史遵循 Ticket 25 的确切脱敏
身份；会话删除则完整移除私有记录。
删除和孤立记录修复先沿不可变执行绑定移除消息，再删除绑定，即使可变的
会话、所有者或索引字段已损坏。绑定消息残留会中止删除，保留跨成员拒绝
所需的事实，并允许重试已核验移除。
执行头已经缺失的终态事件同样遵循此顺序。可变消息执行索引不授权跨成员删除。

显式反馈独立于会话保留，不自动复制转录。可选描述只存在于原始信号；
审核投影关联仍保留的信号，不使用复制元数据。信号删除或过期移除未分类触发项。
已分类决定只保留非个人主题、分类与处置，切断原始引用、去重关联、描述、
元数据及精确提交时间；缺口主题变为 `detached-feedback`。后续完整维护与
finding 工作流属于 Ticket 27。
成员删除反馈在提交成功前核验原始记录和引用均已移除，残留时返回
`PRIVACY_DELETE_UNVERIFIED`。

## 策略与清理

冻结的版本 1 默认值为 `conversations=30`、`operational_events=30`、
`feedback_signals=180` 天，具有规范 SHA-256 `configuration:` 身份。
管理员专属 `GET /retention` 展示策略和非内容清理状态。
`PUT /retention/policy` 要求 `expected_identity` 及 1 至 3650 的严格整数
期限；拒绝零值、停用、畸形值和内容访问开关。注册表锁下追加不可变配置与
策略事件；相同值不变更，过时更新返回 `RETENTION_POLICY_STALE`。

会话和运维事件从创建时间而非活动计算过期。新反馈使用有效期限，清理采用
原到期时间与当前创建时间期限中较早者。增大策略期限不能延长已承诺的反馈
到期时间。类别不共享内容存储，也不授予管理员转录访问。

传入请求标识只透传规范 UUIDv4。其他值在响应、日志上下文和运维事件关联
之前替换，不能用自由文本请求头形成内容遥测字段。

策略变更暂停受影响验收。Pilot、Daily-Use、Public Evidence 验收必须绑定
当前策略及已核验清理。旧策略、缺失或过时清理阻断部署投影。被暂停记录需要
新验收，清理不会自动恢复。

启动及每 60 秒循环不依赖用户流量，分别以独立事务清理三类数据。
有界表 `retention_cleanup_states` 只保留类别、尝试次数、策略身份、
pending/verified/failed 状态、时间、删除数量、剩余过期数量及规范原因。
删除前提交 pending，verified 与已核验删除在同一事务提交。会话核验包含
孤立消息、执行头和事件。
反馈核验包含孤立审核引用，即使原始信号已消失，重试也会重新发现它们。
失败恢复比较尝试编号，防止旧工作进程覆盖较新的已核验结果。

异常记录 `RETENTION_CLEANUP_FAILED`，不包含异常原文；残留记录产生
`PRIVACY_EXPIRY_SURVIVED`。单类失败不阻止其他类别。管理员专属
`POST /retention/cleanup` 用于重试。缺失、策略过时或超过 180 秒的观察
均为未核验，阻断验收。
未来时间或相互矛盾的观察同样未核验，不投影非规范状态或错误文本。
清理失败还会追加非内容规范失败事件，由受影响在线验收记录的持久化
shared-privacy 部署阻断引用。后续清理成功不能移除该暂停。
失败证据独立于清理状态恢复提交，并绑定确切受影响验收身份，包括已因局部
缺陷暂停的记录；部署阻断与原有局部阻断并存。状态读取校验保留失败证据，
存在更新失败时不能复用旧 verified 观察。即使状态无法持久化，重试响应
也保留本次尝试的失败。
失败证据记录它使哪个锁内观察到的尝试失效，不使用任务启动时间决定失败与
验证的覆盖关系。即使可变状态丢失，新尝试也越过保留的失效编号。新鲜 pending
可被正常并发清理替代，不产生永久失败；超过 180 秒或时间矛盾地位于未来的
pending 观察才作为中断处理。

## 暴露证据

`deploy/production/compose.yml` 是支持的 Pilot 形态：仅 Caddy 发布
80/443，基础设施及后端无主机端口，应用网络为内部网络。HTTPS 证书、
明文重定向或拒绝、已认证用户路径及外部暴露仍需要部署证据。
同一部署形态在不启用 HTTP/3 时可以省略 Caddy 的 UDP 443 映射；
TCP 80/443 仍是唯一允许发布的 TCP 端口。

```bash
cd backend
uv run python -m app.operations.exposure \
  --compose ../deploy/production/compose.yml \
  --source-revision <exact-source-sha> \
  --output <private-evidence-directory>/exposure.json \
  --authorized-host <authorized-deployment-dns> --all-tcp-ports --tcp-workers 1
```

仅探测明确获授权的主机。报告只含哈希、修订、时间、端口范围和布尔结果，
不含主机、凭据或正文。完整 TCP 模式只允许 SSH 和 HTTP/HTTPS；默认有界
模式检查声明的基础设施端口。UDP 与防火墙检查是独立义务，超时表示探测
未完成，不能证明端口关闭。TCP 探测默认使用四个并发连接；
`--tcp-workers` 接受 1 至 64，受限链路使用一个工作线程。
降低并发不会缩减端口范围，也不会将超时改判为端口关闭。不提供
`--authorized-host` 的纯配置运行故意非零退出，保留
`live_exposure_verified=false`，不能作为公网 Pilot 通过证据。
