# ADR 0007：Pilot 安全与独立保留策略

状态：已接受

日期：2026-09-09

扩展 ADR 0001、0002、0004、0006，不改变身份、发布、封闭结果或撤回语义。

## 决策

采用规范 [Pilot 安全与保留策略契约](../contracts/pilot-safety-retention.zh-CN.md)。
来源准入成为负责的编辑审核中不可变的一部分。不能从旧 public/internal
标签推断全员获授权及限制敏感度权威。既有工件身份保持不变。

分别保留 30/30/180 天默认值及不可变策略版本。通过确切身份比较和受影响
验收暂停保护更新。配置不能启用转录浏览、停用过期或合并数据类别。
独立调度清理沿用私有写入隔离，并使用新的有界非内容观察表。失败或未核验
清理阻断部署验收，不仅是面板计数。

描述只存在于原始反馈。追加迁移移除旧审核项副本。读取关联保留信号；
删除或过期切断引用，保留已经分类的非个人决定。完整维护工作流仍属于
Ticket 27。

## 后果

部署必须执行 `20260909_0026`。缺少审核准入的来源需要显式重新审核，
不回填臆造权威。本地检查不能证明公网 HTTPS 或网络隔离；暴露工具把
纯配置运行标为真实验证未通过。本决策不提供通用个人信息、密钥检测、
网络安全或 Prompt Injection 保证。
