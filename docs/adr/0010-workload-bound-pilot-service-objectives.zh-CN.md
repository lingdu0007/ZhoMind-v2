# 绑定工作负载的 Pilot 服务目标

Status: 已接受测量契约；真实 Pilot 验收仍以证据为准。

Date: 2026-09-12

Pilot 以实测的 Pilot Workload Profile 和 KB-SL-001 至 KB-SL-004，
替代历史工作区 ADR 0014 `bound-the-first-single-server-release` 的固定主机
服务承诺与 12 秒 P95。测量负载为八名已准入测试成员、两个执行位置、两个
排队位置、每成员一个执行加一个排队位置，以及一个构建工作进程。
50 个活跃条目和不超过 10,000 个可用于答案的块是实测余量，不是永久发布上限。

历史作品集 c1/c5 性能产物保持不变。其首响应体字节计时不是实际答案内容
TTFT，12 秒目标不是当前 Pilot 目标，旧语料、主机、提供方、配置和观察窗口
也不能授予当前验收。现有 25 成员、500 来源安全护栏和 25 MiB 上传护栏，
在另行配置并验证前仍作为兼容性资源控制保留，但不构成支持这些容量的
Pilot 承诺。本 ADR 不提高这些护栏，不降低发布权限，不改变提供方审批，
也不替代 ADR 0009 的单进程调度规则。

已接受的测量区分准入确认（P95 一秒）、有意义的处理状态（P95 两秒）、
实际答案内容与闭合结果（并发二时 P95 三十秒；每个已准入突发请求包含排队
和全部路由尝试后在六十秒内闭合）。少于 20 个样本不能判定百分位通过或失败。
提供方可靠性与四周核心使用窗口可用性分别衡量：Generation Unavailable
属于产品可用，但不属于路由成功。缺失观测不能成为实测正常运行时间。

性能未达标要求产生关联证据、有负责人和期限的决策，而不是撤回仍然有效的
知识。[Pilot 测量契约](../contracts/pilot-measurement.zh-CN.md) 定义当前接口、
报告边界以及剩余部署义务。
