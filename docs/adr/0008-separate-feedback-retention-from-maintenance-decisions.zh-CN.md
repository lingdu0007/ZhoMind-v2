# ADR 0008：分离反馈保留与维护决策

状态：已接受

日期：2026-09-11

## 决策

明确反馈保留在可删除、有期限的存储中；维护决策使用规范化不可变快照和只追加事件。
独立的可删除链接将仍保留的信号连接到决策。
[知识反馈与维护契约](../contracts/knowledge-maintenance.zh-CN.md)规范资格、独立验证、
停用与维护节奏。本决策扩展 ADR 0007，将 Helpful 自动创建工作替换为采用信号记录；
旧复核行不因此取得规范化权威。

不得把原始或仅匿名化的会话提升为持久 Finding。Work Owner 有意独立编写并验证
非个人场景，Maintainer 批准规范化结果。重放必须证明实际条件、发布版本和检索策略；
拥有历史执行本身不能证明当前执行来源。

不可变 fixture 只保留独立验证场景的请求摘要和完整 Query Condition Set 标识，不保留
重放请求正文或私有回答标识。每次重放都需要明确选择当前属于本人的私有执行，并在
运行前核对两项绑定。可删除信号的结构化条件摘要将独立编写场景关联到报告，不要求
问题正文相同。拒绝仅凭 Work Owner 勾选合成材料确认就把问题保留在不可变 fixture
中的方案，因为这会产生不可删除的会话副本。代价是删除私有场景输入后，必须独立
重新编写输入才能重放，不能从维护证据恢复正文。

未解决的 P0/P1 决策直接作用于普通检索和回答完成阶段，而不是期待暂停内容验收间接
改变编辑资格。迟到的阻断与回答提交通过同一写入锁确定先后。明确的 Work Owner
验证只能在请求级、当前仍有效的上下文中排除本事项的阻断；其他事项、编辑与来源
权威以及 Provider 准入仍有效。fixture／重放保留该上下文的封闭来源证据。这样可以
在重新验收之前验证修复，而不在修复期间重新开放普通流量。

对于 P0/P1 Provider 诊断，本决策扩展 ADR 0005：普通路由捕获仍暂停，但允许明确授权
的请求级验证。管理员签发精确的维护、场景和发布范围以及单独完整批准的路由准入；
作为普通成员的 Work Owner 执行非个人复现或已批准的修复重放。准入和最终确认均
重新验证权限。保留授权来源，不虚构路由激活。此路径不放宽 Provider 或数据审批，
不发布路由，也不替代修复后验收。被否决的方案是仅为测试修复是否有效而先激活路由，
因为这会在有界修复场景验证前暴露普通流量。

## 影响

调查报告可能需要独立复现，而不是打开报告人的会话。这增加工作量，但使信号删除与
过期既不抹除合法的非个人决策，也不保留隐蔽的会话副本。另一种被否决的方案是把反馈
复制到不可变事件或 Finding，再尝试事后脱敏；它同时违背只追加权威和可验证删除。

维护不自动改变已发布知识。修复必须使用既有编辑、来源、验收和发布权威。
路线图资格只记录独立的有界决策，不授予实施新范围的权限。新增的 `20260911_0027`
迁移仅创建可删除的维护信号链接，不为旧记录虚构责任或 Finding。
